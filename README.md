# Conn3x packages

The apt and dnf repositories for [Conn3x](https://conn3x.org), served from GitHub Pages at `https://conn3xorg.github.io/packages`. Each release updates them, from the signed `.deb` and `.rpm` files on the [releases page](https://github.com/conn3xorg/conn3x/releases).

The `gh-pages` branch is rebuilt from scratch each time by `.github/workflows/packages.yml` in conn3xorg/conn3x, so don't commit to it by hand. Setup steps are on the [install page](https://docs.conn3x.org/install).

Found a problem? Open an issue on [conn3xorg/conn3x](https://github.com/conn3xorg/conn3x/issues).
